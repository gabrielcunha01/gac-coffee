# ☕ GAC Coffee

Landing Page moderna desenvolvida para uma cafeteria de alto padrão, unindo conceitos avançados de Design Gráfico com desenvolvimento Front-end.

### 🎨 Diferenciais de Design:
- **Identidade Visual:** Uso de paleta de cores harmonizada (#d3ad7f) para transmitir sofisticação.
- **Tipografia:** Implementação da fonte Roboto para legibilidade e modernidade.
- **UI/UX:** Interface focada na experiência do usuário e conversão.

### 🛠 Tecnologias:
- HTML5 Semântico
- CSS3 (Variáveis, Flexbox e Grid)
- Font Awesome Icons
- Google Maps API (Iframe)
